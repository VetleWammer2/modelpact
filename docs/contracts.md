# Behavior contracts

Behavior Contract v1 is strict YAML/JSON data. `compile.objectives` are
differentiable proxies; `verify.targets` and `verify.guards` are executed
acceptance rules. Generative rules require autoregressive evaluation under the
recorded decoding policy. Prompt-level outputs and parser results are retained.

Static checking catches only justified contradictions, such as different exact
outputs for the same exact input or opposed choice margins. Finding no static
contradiction does not establish satisfiability.
