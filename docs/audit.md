# Higher-order audit

Small pools can execute every nonempty subset (with the empty baseline recorded
separately by default). Larger pools fit a sparse pseudo-Boolean surrogate to
executed contract margins, actively propose uncertain or predicted failing
subsets, execute them, and update the surrogate. Any failure is reduced with
executed ddmin removal tests. Surrogate predictions are never certificates.

The current audit record retains fit summaries and active proposal scores, not
the complete fitted coefficient/ensemble state. Its CLI JSON envelope is hashed,
but it is not yet a standalone strictly parsed portable artifact schema.
