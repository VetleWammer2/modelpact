# Benign collusion example

The committed configuration executes a bounded higher-order audit. Singletons
and relevant pairs pass; an executed three-way combination violates a harmless
required-output margin. Active selection is a search heuristic, while the model
execution is the oracle.

```console
python benchmarks/run.py \
  --config examples/benign_collusion/config.json \
  --output artifacts/examples/benign-collusion.json
```

Read `configuration.offline`, the audit coverage grade, executed-subset count,
found failures, reduction evidence, and budget flag together. The bounded run
must not be described as an exhaustive audit or as recovering a minimal failure
unless executed reduction evidence supports that claim.
