# Changelog

All notable project changes are recorded here. ModelPact follows semantic
versioning after the first tagged release.

## Unreleased

### Added

- Initial R1 package foundations for model identity, Behavior Contract v1,
  content-addressed additive delta programs, patch bundles, runtime mounting,
  materialization, and independent verification.
- Deterministic tiny decoder and safe local Hugging Face adapter boundaries.
- Contract-guided low-rank compilation, counterexample search, behavioral diff,
  selective extraction, composition closure, semantic merge, higher-order audit,
  and semantic rebase research engines.
- Executed CPU ModelPactBench workflows for selective extraction, a real tiny-LM
  composition conflict/semantic merge/rebase/revert loop, exhaustive and active
  audit organisms, and CEGIS negative-case retention.
- A fully offline, generated one-layer GPT-NeoX workflow with two compiled
  patches, closed composition, verified direct rebase, sealed holdout, and two
  package-independent standalone verification executions.
- Standalone package-independent patch apply and verify script generation.
- Metadata-planned, atomic SafeTensors materialization that processes one output
  shard at a time and records I/O, shard, wall-time, and available peak-RSS
  measurements without claiming constant memory.
- Offline CI/research workflows, benchmark configurations, contributor guidance,
  and local Hugging Face preflight instructions.

### Research status

No tagged R1 release or GPU benchmark result is claimed by this changelog. The
retained local Hugging Face result covers only the generated one-layer GPT-NeoX
fixture and is not a compatibility claim for arbitrary Transformers checkpoints.
Release results are recorded only with reviewed raw machine-readable artifacts
and an environment manifest.
